## Sobre mim

Atualmente estudo **Engenharia da Computacao** e venho construindo minha base em desenvolvimento web, logica de programacao, sistemas e projetos embarcados.

Gosto de transformar ideias em projetos praticos: de interfaces web responsivas a experimentos com Arduino, sempre buscando escrever codigo mais organizado, entender melhor as ferramentas que uso e evoluir um pouco a cada entrega.

No momento, estou focado em:

- Desenvolvimento web com **React, TypeScript, JavaScript, HTML e CSS**
- Projetos que unem **software e hardware**
- Organizacao de portfolio, documentacao e boas praticas de versionamento
- Aprendizado continuo em estruturas de dados, APIs e arquitetura de aplicacoes
